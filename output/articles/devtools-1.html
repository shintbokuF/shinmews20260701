Claude CodeのHTMLプレビュー脆弱性で秘密情報漏えいの恐れ、開発者ツールの“便利機能”が新たな攻撃面に

  • Claude CodeのHTMLプレビューに重大欠陥が見つかった。
  • 悪意あるJavaScriptがローカル秘密情報へ触れ得る。
  • AI開発ツールの安全設計が改めて問われている。

AnthropicのClaude Code Desktopに、HTMLプレビューを悪用して開発者の秘密情報を盗める重大な脆弱性が見つかった。SSH秘密鍵やAWS認証情報、ClaudeのOAuthトークンまで流出しうるとされ、AI開発ツールの安全設計が改めて問われている。

A critical flaw in Anthropic’s Claude Code Desktop could let attackers steal developers’ secrets via the HTML preview pane. The issue highlights how AI developer tools can create new attack surfaces if preview and file-access features are not tightly sandboxed.

Anthropicの開発者向けツール「Claude Code」に、HTMLプレビュー経由で秘密情報を抜き取られ得る重大な脆弱性が見つかった。Dark Readingは、この不具合により開発者のSSH秘密鍵やAWS認証情報、ClaudeのOAuthトークンなどが静かに盗まれる可能性があると報じている[1]。CSO Onlineも同様に、HTMLプレビューの仕組みに欠陥があり、悪意あるJavaScriptがローカルファイルへアクセスしてクラウド認証情報を持ち出せると伝えた[2]。

ポイントは、攻撃にユーザー操作がほとんど要らないとみられることだ。Dark Readingは「no prompt, no click」と表現しており、気づかないうちに漏えいが進む“ゼロクリック”系の危険として警戒を促している[1]。CSO Onlineの説明では、単にClaude CodeにHTMLファイルのレビューを依頼するだけで、攻撃者が開発者端末やクラウド資格情報、開発環境へ近づけてしまう可能性があるという[2]。

この件は、AI開発ツールやエージェント系フレームワークが便利になるほど、プレビュー表示・ファイル参照・ローカル連携といった機能が新しい攻撃面になることを示している。Anthropicの他のAI関連の動きとしては、高リスク評価に使う内部AIモデルをインターネットから切り離したとBleepingComputerが報じており、AIシステムの外部接続や安全境界をどう設計するかが業界全体の論点になっている[3]。さらに、開発者向けAIツール自体を狙う攻撃や偽装配布も観測されており、Security Boulevardは偽Claudeインストールページがマルウェア配布に使われた事例を紹介している[4]。開発現場では、AIにコードを見せるだけでなく、プレビューや権限、認証情報の扱いまで含めて見直す必要がありそうだ。
