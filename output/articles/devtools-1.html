Claude Code Desktopの「SneakPeek」脆弱性、ゼロクリックで開発者の鍵やAWS認証情報が漏えいする恐れ

  • Claude Code Desktopの表示機能に脆弱性が見つかった。
  • 悪意あるHTMLだけで秘密情報が盗まれうる。
  • エージェントログでは追跡しにくい点が問題だ。

Claude Code Desktopのプレビュー表示機能に起因する「SneakPeek」脆弱性が報告され、悪意あるHTMLだけでSSH秘密鍵やAWS認証情報などが盗まれる可能性があるとされています。[1][2] エージェントが実行した操作ではなくプレビュー描画の問題であるため、従来のエージェントログでは検知しにくい点も懸念されています。[2]

A reported “SneakPeek” flaw in Claude Code Desktop’s preview pane may let attackers steal SSH private keys, AWS credentials, and other secrets through malicious HTML alone, with limited visibility in agent-level logs.[1][2]

Claude Code Desktopのプレビュー表示に関する「SneakPeek」脆弱性が、開発者向けツールの安全性に改めて注意を促しています。報道によれば、この不具合はプレビュー・ペインの描画処理に入り込む形で悪用され、SSH秘密鍵やAWS認証情報などの機密情報を、開発者が気づかないうちに抜き取られる恐れがあります。[1][2]

ポイントは、これが“ゼロクリック”型の脅威として扱われていることです。つまり、ユーザーが明示的に危険な操作をしなくても、表示されたコンテンツそのものをきっかけに情報漏えいが起こりうるということです。Dark Readingは、Claude Code Desktopのプレビュー・ペインにあるバグが、開発者の認証情報を静かに盗ませる可能性を指摘しています。[1]

また、検知の難しさも見逃せません。Hackreadは、このスクリプトがエージェントの判断や実行ではなく、プレビュー・ペインのレンダリング処理で動いたため、エージェントレベルのログには通常現れないと説明しています。[2] つまり、AIエージェントの挙動だけを監視していても、今回のような表示系の攻撃は見逃される可能性があります。

開発者ツールやAIエージェントの利用が広がるなかで、利便性と同時に「どの層で何が実行されるのか」を意識する必要があります。Claude Codeのような開発支援ツールは、コード生成や自動化を加速する一方で、プレビューや外部入力の取り扱いが弱点になると、認証情報の流出という直接的な被害につながりかねません。[1][2] 今回の件は、AI開発ツールのセキュリティが、モデルの性能だけでなく表示機構や実行環境まで含めた全体設計で問われる段階に入っていることを示しています。
