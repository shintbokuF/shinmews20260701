MicrosoftとAWS、Azure–AWS連携を共同管理型で公開プレビュー　マルチクラウド接続をAPI/IaCで統一

3行でわかる！今日のニュース
  • AzureとAWSが直結接続を公開プレビュー
  • API/IaCで接続管理を共通化する
  • 速度は当初1Gbps、将来100Gbpsを視野

Microsoft AzureとAWSが、相互接続を共同管理型で扱う新しいマルチクラウド接続を公開プレビューにしました。open API specificationを土台に、APIやIaCで接続を管理しやすくするのが特徴です。

Microsoft Azure and AWS have previewed a jointly managed multicloud interconnect, using an open API specification and enabling API/IaC-based control of cross-cloud connectivity.

MicrosoftとAWSが、AzureとAWSを直接つなぐ新しいマルチクラウド接続を公開プレビューしました。背景にあるのは、従来は複雑だった両クラウド間のネットワーク構築を、より標準化された形で扱いたいという需要です。[3][4]

この仕組みの要点は、AWSが2025年末に導入し2026年4月にGA化したopen API specificationを、MicrosoftがAzure側でも採用したことです。両社はそれぞれのインフラをこの仕様に沿って連携させ、APIベースで相互運用しやすい接続モデルを目指しています。[2][4]

今回の連携は、AWS側のバックボーンにAzureが“第三の直接接続先”として入る形で説明されています。これにより、エンジニアはAmazon VPCをAzureに向けて直接結ぶような構成を、従来より扱いやすくなる見込みです。[1]

ただし、公開プレビュー段階では速度上限が1Gbpsに抑えられている点が重要です。一方で、将来的には最大100Gbpsまで見据えた設計が示されており、まずは管理と相互接続の標準化を優先しつつ、後から大容量化を進める段取りと読めます。[1][4]

クラウド各社はAIワークロードの拡大で、単一クラウドに閉じない構成への対応を急いでいます。今回の発表は、AWSとAzureが競合関係にありながらも、マルチクラウド運用の“面倒な接続部分”を共同で整備する方向へ踏み出した点で象徴的です。[2][3]
