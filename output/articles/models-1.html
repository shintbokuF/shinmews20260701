Meta、端末型コーディングエージェント「Muse Code」を公開　Claude CodeやCodexに挑む

3行でわかる！今日のニュース
  • MetaがMuse Codeを公開し対抗軸を明示した。
  • 端末内で計画・実装・検証まで進める。
  • macOS/Linuxベータで価格面も攻める。

Metaが2026年8月5日、初のAIコーディングエージェント「Muse Code」を公開しました。端末で動作し、複雑なリポジトリ向けに計画・実装・検証までこなす点が特徴で、AnthropicのClaude CodeやOpenAIのCodexに正面から対抗します。公開範囲はmacOSとLinuxのベータで、基盤モデルのMuse Spark 1.2と組み合わせた設計や、価格面での優位性も注目されています。

Meta launched Muse Code on August 5, 2026, its first AI coding agent. It runs in the terminal, can plan, write, and validate code for larger repositories, and is now in beta on macOS and Linux. The release positions Meta against Anthropic’s Claude Code and OpenAI’s Codex, with a claimed pricing edge and tight integration with Muse Spark 1.2.

Metaは2026年8月5日、同社初のAIコーディングエージェント「Muse Code」を発表した。端末上で動くこのツールは、単に補助的にコードを書くのではなく、大きなリポジトリに対して自律的に計画を立て、実装し、結果を確認するところまで担うという。Meta自身がClaude CodeやCodexの対抗製品と位置づけており、生成AIの主戦場が「会話型」から「作業代行型」へ移っていることを象徴する動きだ。[1][5][7]

注目すべきは、Muse Codeがターミナル中心に設計されている点だ。情報系メディアの報道では、macOSとLinux向けのベータとして提供され、複雑なソフトウェア開発タスクを扱えるとされている。[1][5][6] これは、ブラウザやIDEに閉じない“実務の現場”で使う前提を示している。さらに、デモでは動画ファイルを入力して視覚的にリッチなWebサイトを生成する例も紹介されており、コード生成にとどまらないマルチモーダルな応用力も示唆された。[2]

技術面では、Muse CodeはMetaのモデル「Muse Spark 1.2」と強く結びついているとされる。Neowinの報道によれば、両者は一緒に訓練されており、Muse CodeはMuse Spark 1.2に最適な“ハーネス”だという位置づけだ。また、会話中に都度ワーカーを作り直すのではなく、バックグラウンドのサブエージェントをセッション全体で維持する設計が採られている。[3] この構成は、長い文脈をまたぐ修正や大規模コードベースでの反復作業に向いていると考えられる。

一方で、Metaは価格面でも攻勢をかける。複数ソースは、Muse CodeがAnthropicやOpenAIの競合製品よりも安価に使えるように設計されていると伝えており、機能だけでなくコストでも差別化を狙っていることがうかがえる。[4] 生成AIのコーディング支援は、性能競争に加えて“継続利用できる価格か”が導入判断を左右する段階に入っている。Metaの今回の投入は、モデル性能、エージェント設計、価格戦略を一体で競う新しい競争局面の始まりとみるべきだ。[4][5]

総じてMuse Codeは、MetaがAI開発基盤の競争に本格参入したことを示す象徴的な製品だ。Claude CodeやCodexが切り開いた「コードを書くAI」を、Metaは端末ベースのエージェントとして再定義しようとしている。今後の焦点は、ベータ提供の段階でどこまで実務に耐えるか、そしてMuse Spark 1.2との組み合わせが競合に対してどこまで優位性を持つかに移るだろう。[1][3][5][7]
