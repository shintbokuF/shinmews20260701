Googleが「Nano Banana 2.1」を公開　画像出力料金は「Nano Banana 2」の約半額に

3行でわかる！今日のニュース
  • GoogleがNano Banana 2.1を公開し、画像生成を強化した。
  • APIの画像出力料金はNano Banana 2の約半額になった。
  • 品質向上と一貫性改善をうたい、実用性を高めた。[1][2][3][6]

Googleは画像生成/編集AI「Nano Banana 2.1」を公開し、Gemini APIでの画像出力料金を前世代比で大きく引き下げた。1K画像は0.0336ドル、2Kは0.0504ドル、4Kは0.0756ドルで、Nano Banana 2のおよそ半額となる。[1][3][6]

Google has released Nano Banana 2.1, an image generation and editing AI, while cutting Gemini API image output pricing to about half of the previous generation. The model is positioned for improved image generation, interactive editing, character consistency, and text rendering.[1][2][3]

Googleは10月6日、画像生成/編集AIモデル「Nano Banana 2.1」を公開した。今回の特徴は、単に新バージョンを出したというより、開発者向けのAPI価格を大きく下げながら、画像生成と対話型編集の使い勝手を底上げした点にある。Gemini APIの料金ページは同日に更新され、Nano Banana 2.1は「Nano Banana 2（Gemini 3.1 Flash Image）のアップデート」と説明されたという。[2][5]

価格面では、APIの画像出力がかなり攻めた設定になった。100万トークンあたりの画像出力料金は30ドルで、画像1枚に換算すると1Kが0.0336ドル、2Kが0.0504ドル、4Kが0.0756ドル。[3][1] これはNano Banana 2の1K 0.067ドル、2K 0.101ドル、4K 0.151ドルと比べると、ほぼ半額の水準だ。上位のNano Banana Proよりも安く、しかも用途によっては十分な品質が期待できるため、低コストで大量生成したい開発者にはかなり魅力的な選択肢になりそうだ。[1][3][5]

機能面では、視覚品質の向上に加えて、マルチターンでのキャラクター一貫性、正確なテキスト描画、検索に基づく生成が打ち出されている。[2] ITmedia NEWSによると、Gemini APIではモデルID「gemini-nano-banana-2.1」として提供され、無料ティアはなく有料ティアのみで利用できる。[3] つまり、Googleはこのモデルを“お試し向け”ではなく、本格的な商用利用を意識した実務向けの画像AIとして位置づけていると見てよさそうだ。

他方で、万能というわけではない。流通している解説では、小さな文字や長い段落の描画がぼやけることがある点も指摘されている。 とはいえ、別媒体では4K直接出力や中国語組版の改善、さらに連続画像編集に関する評価が取り上げられており、実運用に近い場面での完成度は確実に上がってきているようだ。[6][7]

総じてNano Banana 2.1は、Googleが画像生成AIの「価格」と「品質」の両面で攻勢をかけたモデルと言える。OpenAIやAnthropicなどとの競争が続く中で、GoogleはGemini系の画像生成を“安く、速く、実用的に”使わせる方向へ明確に舵を切った。APIコストを半額に近づけつつ、編集や一貫性の強化までまとめて打ち出した今回の更新は、画像AIの商用利用における選択肢を一段広げるものだ。[1][2][3][5]
