Anthropic、Claudeの複数モデルへ不可視テキスト透かしを拡大　検出APIも規制当局向けに提供へ

3行でわかる！今日のニュース
  • Claudeの透かしを旧モデルへ拡大した
  • Mythos 5など複数機種を対象にした
  • 規制当局向け検出APIも用意する

Anthropicが、Claudeの出力に埋め込む不可視テキスト透かしを旧来モデルまで広げた。複数ソースによれば、対象はMythos 5やOpus 4.7、Sonnet 4.6などで、今後は検出APIも規制当局向けに提供される見通しだ。

Anthropic is expanding invisible text watermarking to older Claude models. Multiple sources say the coverage now includes models such as Mythos 5, Opus 4.7, and Sonnet 4.6, alongside a detection API intended for regulators.

AnthropicがClaudeの出力テキストに入れる不可視透かしを、より広いモデル群へ広げている。複数の報道では、11月3日付のリリースノートを根拠に、Mythos 5、Opus 4.7、Sonnet 4.6などの文章にも機械可読な印が付くようになったとされる。すでに新しめのモデルでは同種の仕組みが有効だったが、今回は旧モデル側にも適用範囲を広げた点が大きい。[1][2][4][5]

この変更の特徴は、見た目には分からない一方で、後から「Claude由来の文章か」を判定しやすくするところにある。ある報道は、透かしは利用者本人を特定するものではなく、文章の出どころを識別するためのものだと伝えている。また、別ソースでは、2026年11月16日からさらに旧版モデルへの追加対応が予定されているとされ、Anthropicが段階的に対象を広げている構図が見える。[3][5]

一方で、透かしの導入は万能ではない。The Decoderは、古いClaudeモデルでは透かしを回避しやすいケースがあると報じており、文章を別の形に言い換える「humanizer」のようなツールとの相性も論点になっている。つまり、透かしは生成物の由来確認には有効でも、改変や再編集を完全に防ぐ仕組みではない、ということだ。[2][3]

今回の動きは、生成AIの“出力の真正性”をめぐる規制・監査対応が、モデル性能の競争とは別軸で重要になっていることを示す。AnthropicはClaudeを広く使われるモデル群にまで透かし適用を広げることで、誤情報対策や運用監査のしやすさを高めたい狙いがあるとみられる。今後は、どこまで検出精度を維持しつつ、クリエイティブ用途や業務利用への影響を抑えられるかが焦点になりそうだ。[1][4][5]
