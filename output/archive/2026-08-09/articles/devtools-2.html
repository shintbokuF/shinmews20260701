Vibe-Trading has refreshed its interactive CLI to better visualize live agent work while preserving plain-text output for pipes and non-TTY automation. It now emphasizes clearer transcripts for tool calls, web/data fetches, shell-style actions, Markdown answers, and pipe tables.[1][2]

HKUDSのVibe-Tradingは、対話型CLIを大きく見直しました。起点となるターミナル画面ではバナーやprompt区切りを整理し、前ターンの要約や実行後の所要時間を表示することで、会話の流れを追いやすくしています。[1][2]

今回のポイントは、Claude Code風のactivity railでライブなエージェント作業を見せる設計です。tool call、web/data fetch、shell風action、Markdown回答、pipe tableを、読みやすいtranscriptとして描画するため、開発者は「何をいつ実行したのか」を画面上で把握しやすくなります。[1][2]

一方で、見た目のリッチ化だけに寄せていないのも重要です。pipe実行や非TTY環境では、automationに向いたplain-text出力を維持すると明記されており、対話的な可視化とスクリプト利用の両立を狙っていることが分かります。[1][2]

この方向性は、Claude CodeやCursor、GitHub Copilotのような開発者向けAIツールが重視してきた「人が読む対話」と「機械が扱う出力」の二面性に近いものです。Vibe-Tradingの更新は、エージェント型CLIが単に賢くなるだけでなく、実運用で使える観測性と自動化適性をどう両立するか、という論点を前面に出したものと言えます。[1][2]
