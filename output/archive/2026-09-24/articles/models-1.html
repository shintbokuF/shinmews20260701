AnthropicがClaude Opus 5.5を発表、性能は維持しつつ価格を引き下げ

3行でわかる！今日のニュース
  • Claude Opus 5.5を公開し、価格を引き下げた。
  • 入力4ドル・出力20ドルで、速度も改善した。
  • 思考モードとAPI挙動を開発者向けに変更した。

Anthropicは2026年9月22日、生成AIモデル「Claude Opus 5.5」を公開した。価格は入力4ドル/100万トークン、出力20ドル/100万トークンで、前世代比で約20%の値下げ。高速化や典型的処理費用の圧縮に加え、開発者向けには思考モードやAPI挙動の変更も入った。[1][2]

Anthropic announced Claude Opus 5.5 on September 22, 2026. The model lowers API pricing to $4 input / $20 output per 1M tokens, while improving speed and reducing typical processing costs. It also introduces developer-facing API behavior changes.[1][2]

Anthropicは2026年9月22日、Claudeシリーズの新モデル「Claude Opus 5.5」を公開した。API名は「claude-opus-5-5」で、AWS、Google Cloud、Microsoft Azureを含む複数プラットフォームですでに利用可能とされている。[2]

今回の最大の焦点は、性能競争よりもコスト効率だ。料金は100万トークンあたり入力4ドル、出力20ドルで、前世代のOpus 5から約20%の値下げ。さらにキャッシュ読み取りは0.20ドル/MTokまで下がり、典型的な処理費用は40%減、出力速度も30%以上向上したとされる。[1][2]

能力面では、Opus 5.5は多くの作業でClaude Fable 5.1級の性能を示し、比較対象のOpus 5に対しては作業コストを抑えながら実用性を高めた格好だ。検索結果の記述では、単純に“最上位性能”を誇示するより、同等の成果をより安く出す方向へ軸足を移していることが読み取れる。[1]

一方で、開発者向けには無視できない変更もある。Opus 5.5ではthinking（思考）モードをオフにできなくなり、また蒸留対策として、2026年8月31日以降に作成されたAPIアカウントでは、過去の文脈を書き換えて思考内容を引き出す操作を防ぐ保護が入るとされる。[2]

市場全体で見ると、同じ日にはOpenAIもGPT-6 SolとGPT-6 Lunaを出しており、両社とも“最も賢い”ことより“同等性能をどれだけ安く出せるか”を前面に押し出している。Anthropicの5.5は、生成AIの競争軸が能力の単純な上積みから、料金、速度、運用コスト、開発者制御へ移っていることを象徴する発表といえる。[1][3]
