Anthropic、Claudeを一本化しDocs/Slidesを追加　画面統合で開発・制作の入口を簡素化

3行でわかる！今日のニュース
  • Claudeを一本化し、モード切替をなくした。
  • DocsとSlidesを加え、制作機能を拡張した。
  • Claude Codeは別系統で段階展開される。

Anthropicは2026年9月16日、Claude Coworkを通常のClaudeに統合し、チャットとエージェント的作業の切り替えをやめる方向へ進めた。あわせてDocsとSlidesのベータを追加し、Claude Designも含めた制作機能をまとめて使える形に寄せている。対象はまずPro/Max向けで、Claude Codeは別系統のまま段階展開される。

Anthropic is consolidating Claude Cowork into the main Claude experience, removing the mode switch and adding beta Docs and Slides. The rollout starts with Pro and Max users, while Claude Code remains separate in a staged deployment.

Anthropicは、Claudeの利用体験を「チャット」と「作業支援」に分ける構造から、1つの画面に寄せる。今回の変更では、これまで別扱いだったClaude Coworkを通常のClaudeに統合し、ユーザーがモードを選び直す前提を外した。結果として、Claude側が用途を判断して適切な機能を振り分ける設計に近づいている。[1][2][4]

ポイントは、単なるUI整理ではないことだ。検索結果によると、AnthropicはチャットとCoworkに加え、Artifacts周辺も含めた複数の面を1つの窓にまとめたとされる。これにより、利用者は「会話」「共同作業」「成果物作成」を行き来しやすくなり、AIを使うたびに用途を切り替える手間が減る。[3][4][6]

新たに加わったDocsとSlidesは、文章作成とプレゼン資料作成をClaude内に取り込む動きとして読める。抜粋では、Docs/Slidesに加えてClaude Designも並び、これらをまとめて利用できることが示されている。つまりAnthropicは、開発支援だけでなく、企画書・提案書・説明資料の作成までをClaudeの中に吸収し、制作の入口を一本化しようとしている。[3][6][7]

一方で、開発者向けのClaude Codeは今回の統合対象から外れている。検索結果では、Claude Codeは別のまま残り、今回の統合はProとMaxユーザーから段階的に展開されるとされている。これは、一般的な会話・制作機能と、コーディング寄りのagent体験をあえて切り分け、用途別の強みを保とうとする判断とみられる。[1][2][5][8]

AI開発ツール市場の文脈で見ると、この動きはCursorやGitHub Copilot、LangChain系の「開発中の流れをいかに途切れさせないか」という競争にも重なる。ユーザーが都度ツールを選ぶのではなく、1つの画面で必要な作業へ自然に移れることが価値になってきたためだ。AnthropicはClaudeを単なる対話AIではなく、作業起点の統合環境へ近づけることで、開発と制作の両方で存在感を高めにいっている。[1][3][7]
