Anthropic、Claude Codeのcomputer useをMacでバックグラウンド実行に拡張

3行でわかる！今日のニュース
  • Claudeのcomputer useがMacで裏で動く。
  • 作業中でも同時に任せられるようになった。
  • ただし現時点ではMac版ベータに限られる。

Anthropicは、Claudeのcomputer useをMac上でバックグラウンド実行できるように拡張した。Claudeを前面で見張り続けなくても、別作業をしながら処理を進められるのがポイントだ。[1][2][4]

Anthropic has expanded Claude’s computer use so it can run in the background on Mac. The update lets users keep working while Claude handles tasks behind the scenes.[1][2][4]

AnthropicがClaudeのcomputer useをMacでバックグラウンド実行できるようにしたことで、AIエージェントの使い方が一段と実務寄りになった。[1][2] これまでのcomputer useは「画面を見ながら操作を代行する」印象が強かったが、今回の更新ではユーザーが別の作業を続けている間に、Claudeが裏でタスクを進められる点が目立つ。[1][2]

この変化の意味は、単なる利便性の向上にとどまらない。Anthropicは、デスクトップ上でのcomputer useを前提にしつつも、実際の利用シーンを「待つAI」から「並走するAI」へ寄せてきた。[1][2] つまり、ユーザーがClaudeの操作を逐一監視しなくても、定型的な画面操作やアプリ横断の作業を進めやすくなる。[1][2][4]

公開情報の範囲では、この機能は現在ベータとして提供され、ClaudeのProとMaxプラン向け、かつMac版Claudeアプリに限定されている。[4] つまり、すぐに全ユーザーへ広がるというより、まずはMac上の有料ユーザーを対象に実運用を試す段階とみるのが自然だ。[4]

もっとも、こうした“裏で動く”エージェントは、便利さと引き換えに注意点も増える。セキュリティ関連の報道では、メールクライアントや社内ポータル、開発者ツールを通じて操作権限を持つAIエージェントは、プロンプトインジェクションやソーシャルエンジニアリングの新たな面を生みうると指摘されている。[3] また別の報道では、Claude CodeやCursor、Codexなど複数の開発者向けツールが、悪意ある.git設定に関連するリスクの文脈で取り上げられている。[5] そのため、バックグラウンド実行が広がるほど、権限設計と監査の重要性は増す。[3][5]

開発者ツール全体の流れで見ると、今回の更新はClaude Codeのようなエージェント型開発支援が、単なるコード補助から、OSレベルで動く実行主体へ近づいていることを示す。[1][2][6] AI開発ツールを選ぶ基準も、コード生成の巧さだけでなく、どこまで自律的に、どの環境で、どの権限で動けるかに移りつつある。[1][2][4][6]
