AnthropicのClaude Codeが、Mac上でバックグラウンド動作に対応した。作業中にAIへデスクトップ操作を任せられるため、開発者は別の仕事を進めながらClaudeにクリックや入力、アプリ起動などを実行させやすくなる。一方で、常駐的に権限を持つエージェントとしての性質が強まることで、プロンプトインジェクションやソーシャルエンジニアリングへの警戒も必要になる。[1][2][3]

Anthropic has enabled background computer use for Claude Code on Mac, allowing the agent to keep operating while users work elsewhere. The change strengthens always-on developer workflows, but it also raises security concerns around prompt injection and social engineering.[1][2][3]

AnthropicはClaude Codeのcomputer useをMacのバックグラウンドで動かせるようにした。これにより、Claudeはデスクトップ上でユーザーの代わりにクリックや টাইピング、アプリ起動を行いながら、本人は別の作業を続けられる。[1][3] 9to5Macはこの変更をMac向けのバックグラウンド実行として報じ、Digital TrendsもClaude CodeとClaude Coworkで同様の利用が可能になったと伝えている。[1][3]

このアップデートの意味は、単なる便利機能追加にとどまらない。開発者にとっては、コード周辺の定型作業や情報収集をClaudeに任せやすくなり、常駐型のワークフローが作りやすくなる。AI開発ツールの競争では、CursorやGitHub Copilot、LangChain系エージェントのように「どれだけ人の手を離れて動けるか」が差別化要素になっており、Claude Codeもその方向に一段進んだといえる。[1][3][4]

ただし、常時操作できるエージェントには注意点もある。Cybersecurity Newsは、メールクライアントや社内ポータル、開発ツールをまたいで動く権限を持つAIは、プロンプトインジェクションやソーシャルエンジニアリングの新しいリスクを生むと指摘した。[2] さらに、Anthropic自身が同時期にClaude Fable 5.1とClaude Mythos 5.1を発表し、codingやknowledge work向けの性能強化を打ち出していることからも、同社がモデル性能と実行環境の両面でエージェント活用を前進させていることが分かる。[4]
