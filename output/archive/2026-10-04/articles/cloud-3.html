OpenAIとAWS、Bedrock Managed Agentsを提供開始　AWS内でデータを外に出さないAIエージェント基盤

3行でわかる！今日のニュース
  • AWS内完結のAIエージェント基盤を発表
  • 企業データを外へ出さずに活用できる
  • Agents APIの中核機能をAWSへ移した

OpenAIとAmazon Web Services（AWS）が、OpenAIのエージェント機能をAWS内で完結させる「Bedrock Managed Agents, powered by OpenAI」を発表した。企業はデータをAWSの外へ出さずにエージェントを構築でき、AWSリソースとも接続できるという。[1][2][3]

OpenAI and AWS have announced Bedrock Managed Agents, powered by OpenAI, a managed agent base that runs entirely within AWS so enterprise data does not leave the cloud. The service brings core Agents API capabilities into AWS and connects with AWS resources.[1][2][3]

OpenAIのDevDay 2026で、同社はAmazon Web Servicesと組み、OpenAIのエージェント機能をAWS内でそのまま動かせる「Bedrock Managed Agents, powered by OpenAI」を発表した。検索結果によると、この仕組みでは企業が構築するエージェントのデータがAWSの外へ出る必要がなく、AWS上で完結する形を取る。[1][2][3]

ポイントは、単なる外部連携ではなく、OpenAIのAgents APIの中核機能をAWS向けに持ち込んだ点にある。Windows Reportは、開発者がAWSリソースと接続しながらOpenAI搭載エージェントをAWS内で実行できると説明している。OpenAI公式のDevDay 2026 recapでも、Amazonと協力してAgents APIの能力をAWS向けにカスタマイズしたことが示されている。[2][3]

この発表がクラウド市場で意味を持つのは、AIエージェントの導入障壁になりやすい「データ所在」と「既存クラウド資産との接続」を同時に緩和するからだ。データを外部に持ち出したくない企業でも、AWS内に閉じた形でOpenAIベースのエージェントを使えるため、ガバナンスや運用要件に敏感な業種ほど受け皿になりやすい。[1][2]

一方で、現時点では提供形態は限定プレビューで、AWS側の説明としてもまずは試験導入の位置づけとみられる。DevDay 2026ではOpenAIがAgents APIのComputer Use対応など複数の機能強化も打ち出しており、今回のAWS連携はその拡張線上にある動きと整理できる。[1][2][4]

クラウド各社がAI基盤を競うなかで、OpenAIとAWSの組み合わせは「モデルをどこで使うか」から「どのクラウドの中で安全に動かすか」へ焦点を移す一手だ。特にAWS利用が前提の企業にとっては、生成AIやエージェント活用の実装候補が一段と増えたと言える。[1][3]
