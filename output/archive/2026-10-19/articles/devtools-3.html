Anthropic has generally released Code Review for Claude Code and is offering up to $50,000 in credits for GitHub Enterprise. The rollout comes with notable eligibility and environment restrictions that teams should review before adoption.

Anthropicは、Claude Code向けのCode Reviewを一般提供に切り替えた。対象はTeamまたはEnterpriseプランで、GitHub上のリポジトリを使っている組織だという。[1]

今回の提供範囲には、GitHub Enterprise Serverや、データレジデンシー対応のGitHub Enterprise Cloudも含まれる。一方で、Zero Data Retentionを有効にしている組織や、HIPAA構成を適用した組織は利用できない。[1]

開発者ツールの文脈では、Claude Codeはコード生成だけでなくレビュー支援まで広げてきたことになる。CIやPRレビューの負担を軽くしたい企業にとっては魅力的だが、利用可否は運用ポリシーとGitHub環境の条件を先に突き合わせる必要がある。[1]
