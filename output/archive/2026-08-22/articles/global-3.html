Fortinet、Virtue AI買収で「エージェント時代」の防御を強化

3行でわかる！今日のニュース
  • FortinetがVirtue AIを買収した。
  • AIエージェントの防御機能を拡充した。
  • 企業AIの攻撃面拡大に備える。

FortinetはAIセキュリティ企業Virtue AIの買収を通じて、AI runtime protection、automated validation、autonomous agent securityを自社のSecurity for AIポートフォリオに取り込みました。企業AI導入が広げる新たな攻撃面に対応し、エージェント型AIの安全性確保を急ぎます。

Fortinet has acquired Virtue AI to add AI runtime protection, automated validation, and autonomous agent security to its Security for AI portfolio, aiming to secure the expanding attack surface created by enterprise AI and agentic systems.

FortinetがVirtue AIを買収し、AIセキュリティ戦略を一段と前に進めた。報道各社が伝えるところでは、今回の買収でFortinetはAI runtime protection、automated validation、autonomous agent securityといった機能を取り込み、自社のSecurity for AIポートフォリオを拡張する。[1][3][5][6]

買収の焦点は、いま企業導入が進むエージェント型AIにある。AI MagazineやSecurityInfoWatchなどは、Fortinetが「agentic AI」を安全に使うための防御を強化すると説明しており、AIが自律的に動作するほど、従来の境界型セキュリティだけでは守り切れないという課題意識がうかがえる。[2][3][6]

MSSP Alertは、今回の買収がモデルやプロンプト、AIエージェントを含む企業AIの攻撃面拡大に対応するものだと要約している。つまりFortinetは、AIそのものを使う企業が増えるほど広がるリスクを、運用時点で検証し、実行時点で防御する方向へ持っていこうとしている。[5]

さらにcitybizは、FortinetがGartnerの予測として、AIエコシステムとAIエージェントを守る市場が2026年の28億ドルから2030年には164億ドルへ拡大すると示したと伝えている。この数字は、AIセキュリティが単なる周辺機能ではなく、成長市場として本格化していることを示す材料だ。[8]

総じて今回の買収は、Fortinetがネットワーク防御の会社から、AIの実行環境そのものを守る会社へと守備範囲を広げる動きといえる。特にエージェントが自律的に判断・実行する時代には、事前検証と実行時防御を組み合わせる設計が重要になる。FortinetはVirtue AIの技術をその中核に据え、AI活用の拡大局面で存在感を高めようとしている。[1][2][3][6][8]
