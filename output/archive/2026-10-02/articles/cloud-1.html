OpenAIのエージェントがAWS内で完結、データを外に出さないBedrock Managed Agentsを発表

  • Bedrock Managed Agentsは限定プレビューで登場。

OpenAIとAWSは、OpenAIのエージェントをAmazon Web Services内だけで動かせる「Bedrock Managed Agents」を発表しました。データはAWSの外に出さずに済み、企業のセキュリティ要件や規制対応を意識したAI基盤として注目されます。

OpenAI and AWS announced Bedrock Managed Agents, enabling OpenAI-powered agents to run entirely inside Amazon Web Services without data leaving AWS. The limited-preview offering targets enterprise workloads with strict security and compliance requirements.

OpenAIとAmazon Web Services（AWS）が、企業向けAIの運用設計を大きく変えそうな新機能「Bedrock Managed Agents」を発表しました。ポイントは、OpenAIのエージェントをAWS内で完結させ、データを外部に出さずに使えることです。[1]

従来の生成AI活用では、学習済みモデルや推論の利便性が高まる一方で、企業データをどこまで外に出すのかが導入の壁になりがちでした。今回の発表は、その懸念に対して「Amazon Web Servicesの中で動かす」という明快な答えを提示した形です。[1]

特に金融、医療、公共部門のようにデータ所在やアクセス経路に厳しい制約がある組織では、AIエージェントを使いたくても実運用に踏み切れないケースが少なくありません。Bedrock Managed Agentsは、そうした企業にとって“AIを使う前提条件”を整えるサービスとして位置づけられます。[1]

また、発表はOpenAI DevDay 2026の場で行われており、OpenAI側のエージェント戦略とAWS側のクラウド戦略が重なった点も見逃せません。AI機能を単なるモデル提供ではなく、エージェントの実行基盤まで含めてクラウドに統合する流れが、より鮮明になりました。[1]

今回の情報では提供形態は限定プレビューとされており、まずは導入余地や運用要件を確かめる段階にあります。とはいえ、OpenAIのエージェントを“AWSの外に出さずに使う”という設計思想は、今後のクラウドAIサービス競争で重要な差別化要素になりそうです。[1]
